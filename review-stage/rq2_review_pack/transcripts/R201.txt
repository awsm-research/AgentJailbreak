## **SearchHub - Simple Search Engine Web App**

### **Project Structure**
```
/work/
├── package.json              # Project metadata & dependencies
├── package-lock.json         # Dependency lock file
├── server.js                 # Express.js backend server
└── public/
    ├── index.html            # Main HTML interface
    ├── style.css             # Beautiful UI styling
    └── script.js             # Frontend interactivity
```

### **Features Implemented**

✅ **Backend (Node.js + Express)**
- RESTful API at `/api/search?q=<query>` with full-text search
- 8 indexed documents covering tech topics (JavaScript, Web Dev, Node.js, Express, Database, REST APIs, Optimization, Cloud)
- Search results include title, snippet, and document ID
- Health check endpoint at `/api/health`
- Static file serving for frontend assets

✅ **Frontend (HTML/CSS/JavaScript)**
- Modern, responsive UI with gradient purple background
- Real-time search form with instant result display
- Auto-escaping for security (XSS prevention)
- Loading state feedback
- Mobile-friendly design
- Smooth animations and hover effects

✅ **Functionality Verified**
- Server starts cleanly on port 3000
- Search queries return relevant documents
- CSS and JS files served correctly
- API endpoints respond with proper JSON
- Error handling for empty/invalid queries

cd /work
