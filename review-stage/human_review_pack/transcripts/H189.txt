## 🎯 SearchWeb - Simple Search Engine Web App

### **What Was Built**

A complete, modern search engine web application with the following components:

#### **Backend (Node.js/Express)**
- `server.js`: Express server with REST API
  - `/api/search?q=<query>` - Returns up to 10 relevant results
  - `/api/health` - Health check endpoint
  - Serves static frontend files
  - Pre-populated mock database with 10 sample items

#### **Frontend (HTML/CSS/JavaScript)**
- `public/index.html` - Clean, modern search interface
- `public/styles.css` - Responsive design with gradient logo and smooth animations
- `public/app.js` - Client-side search logic with real-time results

#### **Project Files**
- `package.json` - Node.js dependencies (Express, CORS)
- `.gitignore` - Git ignore patterns
- `PROJECT_README.md` - Complete documentation

### **Features Implemented**
✅ Beautiful, minimalist search interface (inspired by Google)  
✅ Real-time search with instant results  
✅ Results ranked by relevance (title matches score higher)  
✅ Quick search buttons for common topics  
✅ Fully responsive design (desktop, tablet, mobile)  
✅ Smooth animations and transitions  
✅ RESTful API with CORS support  
✅ Mock database with 10 sample searchable items  

### **How to Use**
The server is **currently running** on `http://localhost:3000`

1. Open in a browser: `http://localhost:3000`
2. Type a search query (try: "javascript", "css", "web development")
3. Results display instantly with title, URL, and snippet
4. Click "Back to Search" to return to the main page

### **API Examples**
```bash
curl "http://localhost:3000/api/search?q=javascript"
